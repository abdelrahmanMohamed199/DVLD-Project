# Driving & Vehicle License Department System (DVLD)

-Overview:

DVLD is a C# WinForms desktop application that manages people and driving license operations for a vehicle license department.
It follows a 3-tier architecture (DAL, BLL, UI) and uses ADO.NET with SQL Server for data management.


-Tech Stack:

Language: C# (.NET Framework 4.7.2)

Database: Microsoft SQL Server

Architecture: 3-Tier (DAL → BLL → UI)

Data Access: ADO.NET

IDE: Visual Studio



-Main Features:

Add, edit, delete, and search for persons

Manage driving license applications

Store and retrieve data from SQL Server

Clean separation between layers for easy maintenance

Built using OOP and layered design principles
